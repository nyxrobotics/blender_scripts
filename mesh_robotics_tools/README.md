# Mesh & Robotics Tools

ロボティクス向けのメッシュ補助ツールをまとめた Blender アドオンです。
URDF/xacro 用のバウンディングボックスを生成したり、メッシュを物理演算向けの
ソリッドな単一オブジェクトに変換できます。

含まれるツール:

- **Generate Bounding Box** — 選択メッシュごとにバウンディングボックスを生成し、
  URDF/xacro 用の `<origin>` / `<geometry>` タグを出力します。
- **Make Solid Manifold** — 任意のメッシュを、物理演算向けの「閉じた(watertight)・
  多様体(manifold)・単一オブジェクト」に変換します。複数オブジェクトや分裂した
  パーツも結合してひとかたまりにし、必要に応じて凸形状(非凹)にもできます。

---

## 動作環境

- Blender **2.80 以降**（2.x / 3.x / 4.x / 5.x に対応）
- Make Solid Manifold の **Voxel Remesh** 方式は Blender **2.82 以降**が必要です
  （それ以前では **Convex Hull** 方式を使用してください）。
- バウンディングボックス出力を利用する場合は ROS など URDF を扱う環境

---

## インストール

### Blender 2.80 〜 4.1

1. `mesh_robotics_tools.zip`（解凍不要）を用意します。
2. **編集 > プリファレンス > アドオン** を開きます。
3. **インストール...** をクリックし、zip を選択します。
4. 一覧の **Mesh & Robotics Tools** にチェックを入れて有効化します。

### Blender 4.2 以降

1. **編集 > プリファレンス > アドオン** を開きます。
2. 右上のメニューから **ディスクからインストール (Install from Disk)** を選び、zip を指定します。
3. 一覧で有効化します。

有効化後、必要に応じて **プリファレンスを保存** すると次回以降も自動で読み込まれます。

## 使い方

有効化すると、以下のいずれからでもツールを実行できます。

- **3D ビューのサイドバー**（`N` キー）の **Robotics** タブ
- **Object** メニュー
- **F3**（検索メニュー）からツール名を入力

### Generate Bounding Box

選択したメッシュのバウンディングボックスを生成し、URDF/xacro 用の XML を出力します。

1. 1 つ以上のメッシュオブジェクトを選択します。
2. **Generate Bounding Box** を実行します。
3. 生成結果は次の 3 か所に同時に出力されます（内容は同一）。
   - **クリップボード** — 実行直後にそのまま貼り付けできます。
   - **テキストデータブロック `bounding_box_urdf.xacro`** — テキストエディタで開いて
     閲覧・編集・コピーできます。
   - **システムコンソール** — ログとして出力されます。
4. 実行後にプレビュー用のポップアップウィンドウが表示されます。
   ウィンドウ内の **Copy to Clipboard** から再コピーもできます。
5. 出力された XML を URDF / xacro にコピーして使用します。

**オプション**

| 項目 | 説明 | 既定値 |
| --- | --- | --- |
| `name_prefix` | 生成オブジェクト名のプレフィックス | `UCX_` |

**出力例**

```xml
  <origin xyz="0.1234 0.5678 0.9101" rpy="0.0000 0.0000 1.5708"/>
  <geometry>
    <box size="0.5000 0.3000 0.2000"/>
  </geometry>
```

座標・寸法は Blender の座標系で出力されます。座標系の変換が必要な場合は、
URDF/xacro へのインポート時に行ってください。
生成されたボックスはシーン内にも追加され、視覚的に確認できます。

### Make Solid Manifold

任意のメッシュを、物理演算向けの閉じた多様体の単一オブジェクトに変換します。

1. 1 つ以上のメッシュオブジェクトを選択します（複数可）。
2. サイドバーで方式とオプションを設定します。
3. **Make Solid** を実行します。
4. 処理中はステータスバーに進捗（ステップ名と割合）が表示されます。
   区切りで **Esc** を押すと中断できます（中断時は作業用の複製を削除して元に戻します）。
5. 完成すると、結合・閉じた・多様体化された単一オブジェクトが作成されます。

**方式**

| 方式 | 内容 |
| --- | --- |
| `Voxel Remesh` | 凹凸を保持したまま watertight な単体にします。近接したパーツは結合されます（Blender 2.82 以降）。 |
| `Convex Hull` | 凸包を作成します。確実に 1 つの凸ソリッドになり、離れたパーツも 1 つに統合されます。 |

**オプション**

| 項目 | 説明 | 既定値 |
| --- | --- | --- |
| `Voxel Size` | ボクセルの大きさ。小さいほど高精細で重くなります。離れたパーツを繋ぎたい場合は大きくします。 | `0.01` |
| `Merge Distance` | この距離以内の重複頂点を事前に結合します。 | `0.0001` |
| `元を残す` | 元オブジェクトを残し、結果を別オブジェクトとして作成します。 | オン |
| `原点を体積中心へ` | 結果の原点を体積中心へ移動します（剛体物理に有用）。 | オン |
| `結果の名前` | 作成されるオブジェクトの名前。 | `SolidBody` |

**メモ**

- 離れて配置されたパーツを 1 つにまとめたい場合は、`Convex Hull` を使うか、
  `Voxel Size` をパーツ間の隙間より大きくしてください。Voxel Remesh は、
  ボクセルサイズより離れたパーツは繋ぎません。
- 大きなメッシュの Voxel Remesh など、1 つの重い処理の途中では中断が効きません。
  中断はステップの区切りで反映されます。

## トラブルシューティング

- **出力をコピーしたい**: 生成結果はクリップボードへ自動コピーされ、テキスト
  データブロック `bounding_box_urdf.xacro` にも保存されます。実行後のポップアップ
  ウィンドウからも再コピーできます。コンソールにも出力されます
  （Windows は「システムコンソールの切り替え」、macOS / Linux はターミナルから
  Blender を起動）。
- **メッシュではない / 選択がないと言われる**: Make Solid Manifold はメッシュ
  オブジェクトの選択が必要です。Generate Bounding Box も同様です。
- **Voxel Remesh が使えない**: Blender 2.82 以降が必要です。それ以前のバージョン
  では方式を `Convex Hull` にしてください。
