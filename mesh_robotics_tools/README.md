# Mesh & Robotics Tools

ロボティクス向けのメッシュ補助ツールをまとめた Blender アドオンです。
選択メッシュから URDF 用のバウンディングボックスを生成したり、メッシュの
簡略化・形状再構成を行えます。

含まれるツール:

- **Generate Bounding Boxes** — 選択メッシュごとにバウンディングボックスを生成し、
  ROS(URDF) 用の `<origin>` / `<geometry>` タグを出力します。
- **Simplify & Reconstruct Mesh** — メッシュの簡略化（Decimate）と形状の再構成
  （平面/曲面の検出・接続、交差切断、隙間埋め、多様体化）を行います。

---

## 動作環境

- Blender **2.80 以降**（2.x / 3.x / 4.x / 5.x に対応）
- バウンディングボックス出力を利用する場合は ROS など URDF を扱う環境

---

## インストール

### Blender 2.80 〜 4.1

1. `mesh_robotics_tools.zip`（解凍不要）を用意します。
2. **編集 > プリファレンス > アドオン** を開きます。
3. **インストール...** をクリックし、zip を選択します。
4. 一覧の **Mesh & Robotics Tools** にチェックを入れて有効化します。

### Blender 4.2 以降

1. **編集 > プリファレンス > アドオン** を開きます。
2. 右上のメニューから **ディスクからインストール (Install from Disk)** を選び、zip を指定します。
3. 一覧で有効化します。

有効化後、必要に応じて **プリファレンスを保存** すると次回以降も自動で読み込まれます。

## 使い方

有効化すると、以下のいずれからでもツールを実行できます。

- **3D ビューのサイドバー**（`N` キー）の **Robotics** タブ
- **Object** メニュー
- **F3**（検索メニュー）からツール名を入力

### Generate Bounding Boxes

選択したメッシュのバウンディングボックスを生成し、URDF 用の XML をコンソールに出力します。

1. 1 つ以上のメッシュオブジェクトを選択します。
2. **Generate Bounding Boxes** を実行します。
3. システムコンソールに XML が出力されます。
   - Windows: **ウィンドウ > システムコンソールの切り替え**
   - macOS / Linux: ターミナルから Blender を起動して確認します。
4. 出力された XML を URDF にコピーして使用します。

**オプション**

| 項目 | 説明 | 既定値 |
| --- | --- | --- |
| `name_prefix` | 生成オブジェクト名のプレフィックス | `UCX_` |

**出力例**

```xml
  <origin xyz="0.1234 0.5678 0.9101" rpy="0.0000 0.0000 1.5708"/>
  <geometry>
    <box size="0.5000 0.3000 0.2000"/>
  </geometry>
```

座標は ROS 座標系（X 前方・Y 左・Z 上）に変換して出力されます。
生成されたボックスはシーン内にも追加され、視覚的に確認できます。

### Simplify & Reconstruct Mesh

アクティブなメッシュを簡略化し、形状を再構成します。

1. 対象のメッシュオブジェクトをアクティブにします。
2. **Simplify & Reconstruct** を実行します。
3. 処理の進捗・結果はシステムコンソールに出力されます。

**オプション**

| 項目 | 説明 | 既定値 |
| --- | --- | --- |
| `Max Vertices` | Decimate の目標頂点数（これを超える場合のみ削減） | `1000000` |

---

## トラブルシューティング

- **出力が見えない**: 標準出力（print）はシステムコンソールに表示されます。
  Windows は「システムコンソールの切り替え」、macOS / Linux はターミナルから
  Blender を起動してください。
- **メッシュではないと言われる**: Simplify & Reconstruct は、アクティブな
  オブジェクトがメッシュである必要があります。
- **何も生成されない（Bounding Boxes）**: メッシュオブジェクトが選択されているか
  確認してください。
